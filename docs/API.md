# API Documentation

## Commands

All backend operations are exposed through a unified command interface.

### Portfolio Commands
- `getPortfolio()` - Get portfolio summary
- `getHoldings()` - Get current holdings
- `getPerformance()` - Get performance metrics

### Account Commands
- `getAccounts()` - List all accounts
- `createAccount()` - Create new account
- `updateAccount()` - Update account details
